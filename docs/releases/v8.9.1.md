## Принятие выпуска и пределы проверки

Владелец проекта проверил исправление на установленной preview.31 и принял версию 8.9.1. Финальный Setup собирается из тех же файлов launcher и runtime, которые он проверил; целостность пакета сверяется при упаковке. **Независимый полный повторный прогон установленного Setup 8.9.1 не проводился.** Результаты проверки установленной 8.9.0 относятся к [предыдущему выпуску](v8.9.0.md) и не выдаются за проверку 8.9.1.

## Установка и ограничения

1. Полностью закройте ValMAX через значок в трее → «Выход». Крестик может только скрыть окно.
2. Скачайте установщик со [страницы выпуска](https://github.com/govpodi/max-mod-valmax/releases/tag/v8.9.1) и сверяйте его с `SHA256SUMS.txt`.
3. Запустите Setup и откройте ValMAX через ярлык.

Вкладке «Бизнес» и мини-приложениям нужен системный Microsoft Edge WebView2 Runtime. Если его нет, установщику понадобится интернет для получения официального компонента Microsoft либо заранее установленный автономный Runtime.

**Отдельные возможности остаются BETA.** Экспорт сохраняет доступную переписку, фото, видео и голосовые с показом хода скачивания; сервер не подтвердил полноту старой истории, а некоторые вложения могут быть недоступны. Сохранение удалённого текста нужно включить заранее, и оно не гарантирует захват каждого удаления. Раннее применение отдельных защитных настроек и запуск мини-приложений отдельно не подтверждены. Другие условия и сторонние компоненты описаны в [README](../../README.md) и [уведомлениях](../../THIRD_PARTY_NOTICES.md).

## English

**[Download ValMAX 8.9.1 for Windows x64](https://github.com/govpodi/max-mod-valmax/releases/tag/v8.9.1).** The core client is released as stable; individually marked features remain BETA. Reopening ValMAX from its shortcut after closing the window now loads the chat list again. The installed app does not need a separate Python runtime.

Download `ValMAX-8.9.1-Setup.exe` and verify it with `SHA256SUMS.txt`. Exit ValMAX fully from its tray menu before updating. The Qt and FFmpeg archives above contain source materials, are not needed at runtime, and should stay available when redistributing Setup. The FFmpeg archive is reference material; exact corresponding sources and build options for every bundled DLL have not been established.

The owner tested the installed preview.31 and accepted version 8.9.1. The final Setup packages the launcher and runtime files accepted by the owner, with packaging integrity checks. **An independent full regression of the installed final Setup 8.9.1 was not repeated.** The [8.9.0 verification](v8.9.0.md) does not count as 8.9.1 testing.

Chat and media export may be incomplete because the server has not confirmed access to all older messages or attachments. Deleted-message retention applies only after it is enabled and cannot guarantee every event. Early protection readiness and live mini-app launch have not been separately verified. Business and mini apps need the Microsoft Edge WebView2 Runtime; installing a missing Runtime may require internet access.
