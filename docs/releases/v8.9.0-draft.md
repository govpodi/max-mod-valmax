# ValMAX 8.9.0 — черновик заметок / release notes draft

> Черновик для подготовки выпуска. Дату, точные размеры, SHA-256 и результаты проверки установленного финального пакета брать из его квитанции и испытаний; до этого текст не публиковать как подтверждённый релиз.

## Русский

ValMAX для Windows x64 объединяет несколько аккаунтов, быстрые ответы, бизнес-кабинет и настройки приватности в одном клиенте на C++/Qt и Rust. Отдельные Python и локальный HTTP-помощник для работы установленной программы не нужны.

**Компактная установка.** Бизнес-вкладка и мини-приложения используют общий Microsoft Edge WebView2 Evergreen Runtime в Windows вместо отдельной Fixed-копии. Установщик проверяет наличие компонента до обновления. Если его нет, понадобится интернет для загрузки официального установщика Microsoft либо заранее полученный автономный установщик. Исходные материалы Qt и FFmpeg поставляются отдельными файлами и не нужны для запуска ValMAX.

**Удалённые сообщения в чате.** Уже полученный текст, удаление которого клиент наблюдал после включения функции, показывается пузырём с корзинкой прямо в переписке. В локальной preview.29 это проверено в обоих направлениях между двумя собственными аккаунтами с сохранением пузырей и настройки после перезапуска. Итоговая установленная сборка проверяется отдельно. Сохранение каждого события не гарантируется; положение и дата некоторых старых записей могут быть приблизительными или неизвестными.

**Экспорт чата · BETA.** Выбранный чат скачивается через штатный API с предупреждением о возможной неполноте, ходом работы и ограничением темпа запросов. Доступные фото, видео и голосовые сохраняются вместе с HTML; недоступные файлы отмечаются в отчёте. Сервер не подтвердил полноту старой истории, поэтому в архив могут не попасть отдельные сообщения или вложения. Неотправленные сообщения в экспорт не входят.

**Проверка выпуска.** В установленной preview.29 бета-экспорт собственного тестового диалога сохранил 18 сообщений и 6 доступных файлов: 4 фото, 1 видео и 1 голосовое. Ещё 2 вложения архив отметил как недоступные; сигнатуры и SHA-256 скачанных файлов проверены. Перед публикацией остаётся записать итоги наблюдения за фоновым удержанием, проверки точного установленного пакета и контрольные суммы файлов выпуска. Проверки кандидата не заменяют проверку финального установщика. Раннее применение защитных фильтров до первого фонового события остаётся отдельно не подтверждённым.

Перед обновлением полностью закройте ValMAX через значок в трее → «Выход». Со страницы выпуска скачайте установщик и `SHA256SUMS.txt`, затем сверяйте SHA-256. Отдельные исходные архивы перечислены в [сведениях о сторонних компонентах](../../THIRD_PARTY_NOTICES.md).

## English

ValMAX for Windows x64 brings multiple accounts, quick replies, a Business dashboard, and privacy controls into one C++/Qt and Rust client. The installed app needs neither a separate Python installation nor a local HTTP helper.

**Compact Setup.** The Business tab and mini apps use the shared Microsoft Edge WebView2 Evergreen Runtime in Windows instead of a bundled Fixed copy. Setup checks for it before upgrading. If it is missing, you need a network connection for Microsoft's official installer or a separately obtained offline installer. Qt and FFmpeg source materials are separate assets and are not needed to run ValMAX.

**Deleted messages in chat.** Previously received text whose deletion the client observes after the feature is enabled appears as an in-chat trash bubble. Local preview.29 was checked in both directions between two own accounts; the bubbles and setting survived restarts. The final installed package is verified separately. Capture of every deletion event is not guaranteed, and some older entries may have approximate positions or unknown dates.

**Chat export · BETA.** Selected-chat export uses the stock API, warns about possible gaps, shows progress, and paces requests. Available photos, videos, and voice messages are saved with the HTML; unavailable files appear in the archive report. The server has not confirmed complete older history, so some messages or attachments may be missing. Unsent drafts are not exported.

**Release verification.** In installed preview.29, own-chat BETA export saved 18 messages and six available files: four photos, one video, and one voice message. It reported two unavailable attachments; the saved files passed signature and SHA-256 checks. Before publication, record the idle-retention observation, exact installed-package checks, and SHA-256 of every release asset. Candidate checks do not replace final-Setup verification. Early activation of protection filters before the first background event has not been verified separately.

Before upgrading, fully exit ValMAX from its tray menu. Download Setup and `SHA256SUMS.txt` from the release page and verify SHA-256. Separate source archives are described in the [third-party component notes](../../THIRD_PARTY_NOTICES.md).
