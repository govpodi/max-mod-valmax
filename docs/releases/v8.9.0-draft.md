# ValMAX 8.9.0 — черновик заметок / release notes draft

> Черновик для подготовки выпуска. Публиковать после проверки точного установщика, исходных архивов и установленного клиента; размеры, SHA-256 и дату брать из финальной квитанции.

## Русский

ValMAX для Windows x64 объединяет несколько аккаунтов, быстрые ответы, бизнес-кабинет и настройки приватности в одном клиенте на C++/Qt и Rust. Отдельные Python и локальный HTTP-помощник для работы установленного приложения не нужны.

В этом выпуске готовится компактный установщик. Бизнес-вкладка и мини-приложения используют общий Microsoft Edge WebView2 Runtime в Windows; установщик проверяет его наличие до обновления. Исходники Qt поставляются отдельным проверяемым архивом.

Сохранённые после включения функции удаления показываются пузырями с корзинкой прямо в чате. Экспорт выбранного чата показывает ход работы, ограничивает темп загрузки и сохраняет доступные фото, видео и голосовые.

**Ограничение экспорта:** сервер не подтвердил полноту старой переписки. В архив могут не попасть отдельные старые сообщения или вложения; ошибки файлов отмечаются в отчёте. Сохранение удалённых сообщений относится только к событиям, уже полученным клиентом после включения функции.

После публикации скачайте установщик и `SHA256SUMS.txt` со страницы выпуска, сверьте контрольную сумму и полностью закройте работающий ValMAX через значок в трее перед обновлением.

## English

ValMAX for Windows x64 brings multiple accounts, quick replies, a business dashboard and privacy controls into one C++/Qt and Rust client. The installed app needs neither a separate Python installation nor a local HTTP helper.

This release is being prepared with a smaller installer. The business tab and mini apps use the shared Microsoft Edge WebView2 Runtime in Windows; setup checks for it before upgrading. Qt sources are provided as a separate verifiable archive.

Messages retained after the feature is enabled appear as trash-icon bubbles inside the chat. Selected-chat export shows progress, paces downloads and saves available photos, videos and voice messages.

**Export limit:** the server has not confirmed that all older messages are available. The archive may omit older messages or attachments and reports individual file failures. Deleted-message retention applies only to events the client received after you enabled it.

After publication, download the installer and `SHA256SUMS.txt` from the release page, verify the checksum, and fully exit ValMAX from the tray before upgrading.
