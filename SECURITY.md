# Сообщения об уязвимостях

Для уязвимостей используйте [закрытое сообщение через GitHub Security Advisories](https://github.com/govpodi/max-mod-valmax/security/advisories/new), если private vulnerability reporting включён. Укажите версию ValMAX, ожидаемое и фактическое поведение, последствия и минимальные шаги воспроизведения на синтетическом профиле.

Не отправляйте токены, пароли, SMS-коды, Windows credentials, MData/MAXSession-архивы, базы профиля, личную переписку, защищённые ссылки на медиа или необработанные логи. Для примера создайте вымышленные данные. Скриншоты обрежьте и проверьте перед отправкой.

Если закрытая форма недоступна, создайте обычный issue только с просьбой предоставить приватный канал. Не публикуйте детали эксплуатации и чувствительные данные в таком issue. Срок ответа и поддержка старых версий не гарантируются.

## English

Use [GitHub private vulnerability reporting](https://github.com/govpodi/max-mod-valmax/security/advisories/new) when enabled. Include the ValMAX version, impact, and a minimal reproduction using synthetic data. Never share credentials, tokens, SMS codes, MData/session archives, profile databases, messages, protected media URLs, or raw logs. If private reporting is unavailable, open an issue asking for a private channel without exploit details or sensitive data.
