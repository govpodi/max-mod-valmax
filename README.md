# ValMAX — мод мессенджера MAX для Windows

ValMAX — неофициальный мод MAX (МАКС) для Windows x64. Пользуйтесь несколькими аккаунтами, отвечайте готовыми сообщениями и открывайте бизнес-кабинет в одной программе. Доступную переписку можно сохранить вместе с фото, видео и голосовыми сообщениями.

## Возможности

| Возможность | Что она даёт |
| --- | --- |
| Несколько аккаунтов · BETA | До трёх аккаунтов с названиями, цветами и отдельными настройками уведомлений. |
| Быстрые ответы | Готовые сообщения по `/команде`, в том числе с вложениями. Перед отправкой их можно проверить и изменить. |
| Бизнес-кабинет | [business.max.ru](https://business.max.ru/) в отдельной вкладке. Для входа используется собственная авторизация кабинета. |
| Экспорт переписки · BETA | HTML-копия доступных сообщений, фото, видео и голосовых. Видно, как идёт скачивание; архив может быть неполным. |
| Удалённые сообщения · BETA | Если включить сохранение заранее, уже полученное сообщение после удаления может остаться пузырём с корзинкой прямо в чате. |
| Перенос аккаунтов · BETA | MData создаёт защищённый паролем файл для переноса входа в свои аккаунты на другой компьютер. История и медиа в него не входят. |

### Другие настройки

- **Режим призрака** управляет признаками набора текста, прочтения, онлайна и просмотра историй. Изначально выключен.
- **PIN для чата** ограничивает открытие выбранной переписки на этом компьютере и скрывает её превью.
- **Поиск фото и видео** добавляет найденные в Wikimedia Commons файлы в черновик по командам `@pic` и `@vid`. Отправку подтверждаете сами.
- **Приватность и скорость** позволяют настроить диагностику, журналы, загрузку списков и медиа. Часть настроек BETA требует перезапуска.

## Установка

1. На [странице выпуска 8.9.0](https://github.com/govpodi/max-mod-valmax/releases/tag/v8.9.0) скачайте `ValMAX-8.9.0-Setup.exe`. Остальные архивы на этой странице для установки не нужны.
2. Если ValMAX уже запущен, полностью закройте его через значок в трее → «Выход». Крестик или `Alt+F4` могут лишь скрыть окно.
3. Запустите установщик и затем откройте ValMAX через ярлык. Первый запуск может занять до минуты.

Для вкладки «Бизнес» и мини-приложений нужен компонент Microsoft Edge WebView2. Установщик проверит его наличие; если компонента нет, понадобится интернет для загрузки с сайта Microsoft. Отдельно устанавливать Python не нужно.

Файл `SHA256SUMS.txt` на странице выпуска помогает проверить установщик. Размер, контрольная сумма и результаты проверок указаны в [заметках о версии](docs/releases/v8.9.0.md).

## Что важно знать

- **Это неофициальный мод.** ValMAX не связан с командой MAX и использует отдельный профиль на компьютере. Приложение не подписано сертификатом разработчика ValMAX, поэтому Windows может показать предупреждение при запуске.
- **BETA означает, что функция ещё проверяется.** Экспорт может не получить всю старую историю или часть вложений. Сохранение удалённых сообщений работает только для уже полученных сообщений после включения функции и не гарантирует сохранение каждого удаления.
- **Берегите свои данные.** HTML-архив чата не защищён паролем. Файл переноса аккаунтов MData содержит данные входа: храните его и пароль отдельно и не отправляйте другим. PIN ограничивает доступ в самом приложении, но не шифрует базу сообщений.
- **Настройки приватности не дают полной анонимности.** Сервер всё равно получает данные, необходимые для работы аккаунта. Встроенное обновление MAX отключено; новые проверенные версии ValMAX появляются в [GitHub Releases](https://github.com/govpodi/max-mod-valmax/releases).

[Все известные ограничения и результаты проверок версии 8.9.0](docs/releases/v8.9.0.md).

<summary>Подробнее о БЕТА-функциях</summary>

Подробная [инструкция для пользователя](ValMAX-инструкция.txt) также входит в установщик.

- Вложения быстрого ответа могут начать загружаться в черновик до нажатия «Отправить». Само сообщение отправляете вы.
- MData переносит вход, но не переписку, медиа, кэш и пароль двухфакторной защиты. Сервер может снова попросить подтвердить вход.
- Экспорт скачивает доступные вложения по очереди, с паузами между запросами и пределом 4 ГиБ на файл. Недоступные файлы отмечаются в отчёте. У старых сохранённых удалений положение пузыря и дата могут быть приблизительными.
- Настройки «режима призрака» действуют после подтверждения клиентом. Счётчик непрочитанных может вернуться к серверному значению после перезапуска или изменений с другого устройства. Раннее включение защитных фильтров до первого фонового события ещё не подтверждено.
- При обновлении старой модифицированной сборки данные MXMOD сохраняются. Резервная копия программы не заменяет копию данных аккаунтов. Подробности о компонентах и открытых проверках — в [заметках выпуска](docs/releases/v8.9.0.md).
