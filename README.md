# ValMAX — мод MAX для Windows

Неофициальная модификация MAX (МАКС) для Windows x64 с дополнительными возможностями для общения и работы. **Работающий клиент написан на C++/Qt и Rust.** Здесь находятся исходники ValMAX 8.9.0 для базы MAX 26.35.1.80662.

Экспорт сохраняет доступную историю и медиа, но сервер не подтвердил полноту старой переписки. Сохранение удалённых сообщений действует только после включения функции. Ограничения отдельных функций описаны ниже и в [истории изменений](CHANGELOG.md).

## Код проекта

Работающий клиент собран из **C++/Qt и Rust**. Отдельный Python, PyInstaller и локальный HTTP-сервер для запуска не нужны.

| Каталог | Назначение |
| --- | --- |
| [`native/core/`](native/core/) | Rust: локальные настройки и хранилища, MData, экспорт и сохранение удалений. |
| [`native/qt/`](native/qt/), [`native/media/`](native/media/), [`native/hooks/`](native/hooks/) | C++/Qt: интерфейс, медиа, связь с клиентом и нативные обработчики. |
| [`native/launcher/`](native/launcher/), [`native/installer/`](native/installer/) | Нативный запуск и установщик Windows. |
| [`modkit/`](modkit/), [`native/tooling/`](native/tooling/), [`native/tests/`](native/tests/) | Генераторы ресурсов, инструменты сборки, тесты и код прежнего Python-клиента. Часть этих файлов нужна нативной сборке; в установленную 8.9.0 они не входят. |

Языковая диаграмма GitHub выделяет код нативного клиента: Python-файлы прежней реализации, сборки и тестов исключены из неё через [`.gitattributes`](.gitattributes), но остаются доступны в репозитории. Для точной сборки нужен подготовленный baseline MAX и инструменты, описанные в [руководстве разработчика](docs/DEVELOPMENT.md).

## Для работы с клиентами

**Ближе к клиентам. Свободнее в работе.**

| Возможность | Что она даёт |
| --- | --- |
| До трёх аккаунтов · BETA | Телефонные профили с локальными названиями, цветами и отдельным расписанием уведомлений. |
| Быстрые ответы | Шаблоны по `/команде`: общие или для одного аккаунта, с несколькими сообщениями и вложениями. Отправка ручная. |
| Бизнес-кабинет | Официальный [business.max.ru](https://business.max.ru/) в отдельной вкладке ValMAX. Вход самостоятельный, слот телефонного аккаунта не занят. |
| Экспорт чата · BETA | HTML-копия доступной истории, фото, видео и голосовых. Интерфейс показывает ход работы и предупреждает о возможной неполноте. |
| MData · BETA | Компактный перенос авторизованной сессии одного или всех своих аккаунтов, включая нужные ключи MAX из Windows. |

## Другие возможности

- **Режим призрака.** Переключатели фильтров набора текста, прочтения сообщений, онлайна и просмотров историй. По умолчанию выключен.
- **Удалённые сообщения · BETA.** Сохранение уже полученных сообщений при наблюдаемом удалении: пузырь с иконкой корзины появляется прямо в чате. По умолчанию выключено.
- **PIN-код чата.** Локальное ограничение доступа к выбранному чату и скрытие его превью.
- **Приватность.** Отключение проверенных модулей диагностики и статистики, маскировка журналов.
- **Поиск медиа.** `@pic запрос` и `@vid запрос` ищут изображения и видео в Wikimedia Commons по кнопке «Найти». Автор, лицензия и ссылка добавляются в черновик вместе с файлом.
- **Оптимизация · BETA.** Настройки загрузки списков, кэша, фотографий и фоновой работы вкладок. Применяются после полного перезапуска.
- **Встроенный интерфейс.** Настройки разработчика и иконки дополнительных функций в стиле MAX.
- **Помощь и диагностика.** Просмотр и сохранение технического JSON-отчёта для сообщения об ошибке. Отправка вручную.

## Установка

Установщик ValMAX 8.9.0, отдельные архивы исходных материалов Qt и FFmpeg и контрольные суммы перечислены на [странице выпуска v8.9.0](https://github.com/govpodi/max-mod-valmax/releases/tag/v8.9.0). Исходники именно этого выпуска доступны по тегу `v8.9.0`; `main` содержит дальнейшие правки. Точный размер, SHA-256 и результаты проверки установленной версии приводятся в заметках выпуска.

1. Скачайте `ValMAX-8.9.0-Setup.exe` и `SHA256SUMS.txt` со страницы выпуска v8.9.0. Сверьте SHA-256 установщика. Отдельные архивы исходных материалов Qt и FFmpeg для запуска программы не нужны.
2. Полностью закройте ValMAX через значок в трее → «Выход» и сохраните возможность отката. `Alt+F4` может лишь скрыть окно в трей.
3. Запустите установщик и откройте ValMAX через ярлык. Отдельный Python не нужен. Первый запуск может занять до минуты.

**Компактная поставка.** Для вкладки «Бизнес» и мини-приложений используется системный [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Установщик проверяет его наличие; если компонента нет, для загрузки официального установщика Microsoft нужна сеть.

Проверки установленного клиента и известные проблемы конкретной версии перечислены в заметках её выпуска. Экспорт чата остаётся **BETA**: сервер не подтвердил полноту всей старой переписки, а отдельные вложения могут быть недоступны.

<details>
<summary>О данных и функциях с пометкой «Бета»</summary>

Метки **BETA** означают, что функция ещё тестируется. Подробная инструкция входит в установщик.

- При выборе быстрого ответа вложения сразу добавляются в черновик и могут начать загружаться до нажатия «Отправить». Отправка быстрых ответов и найденных медиа остаётся ручной.
- MData не содержит переписку, медиа, кэш и пароль 2FA. Сервер может потребовать повторную проверку входа. Храните архив MData и его пароль отдельно.
- PIN ограничивает доступ локально, не шифрует базу сообщений и не закрывает ранее открытые окна медиа. HTML-копия чата не защищена паролем; недоступные вложения и неполная история отмечаются в отчёте экспорта.
- Экспорт скачивает доступные фото, видео и голосовые последовательно, с ограничением темпа и пределом 4 ГиБ на файл. Часть вложений может быть недоступна. Сохранённые удалённые сообщения относятся только к событиям после включения функции; для старых записей положение пузыря в чате может быть приблизительным.
- Архивы FFmpeg содержат справочные исходные материалы: точное соответствие распространяемым DLL и параметры их сборки ещё не подтверждены. Раннее применение защитных фильтров до первого фонового события также требует отдельной проверки.
- Настройки приватности не обеспечивают полную анонимность: сервер получает адрес подключения и данные, необходимые для работы аккаунта. Режим призрака показывает активный статус после подтверждения фильтров клиентом.
- Локальная поправка счётчика непрочитанных в режиме призрака — BETA, действует в текущем запуске. При перезапуске, удалении сообщений или изменении отметок с другого устройства счётчик может снова показывать серверный остаток. Полная повторная синхронизация ещё требует проверки.
- ValMAX использует отдельный профиль от официального MAX. При обновлении старой модифицированной сборки данные MXMOD сохраняются. Штатное автообновление MAX отключено; публичные сборки и их контрольные суммы публикуются в GitHub Releases после проверки.
- ValMAX не связан с командой MAX. Программа не подписана сертификатом разработчика ValMAX; Windows может показать предупреждение при запуске.
